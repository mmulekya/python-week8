# Week 8 Assignment: Final Project — Personal Mini-Toolkit

## What the Toolkit Does

The Personal Mini-Toolkit is a menu-driven Python program with three tools: a simple calculator, a to-do list manager, and a number checker. The program uses a repeating menu and allows the user to return to the menu after using a tool.

## Files

- `toolkit_plan.txt` — Describes the tools, menu text, and Python concepts used.
- `toolkit.py` — Implements the menu, calculator, to-do list, and number checker.
- `screenshots/` — Contains screenshots showing the menu and tools running.

## How to Run

1. Install Python 3 if it is not already installed.
2. Open PowerShell in the project folder.
3. Run `python toolkit.py`.
4. Choose a tool by entering its menu number.
5. Choose `4` to quit.

## Reflection

The hardest part of this project was organizing the tools so that each one worked independently and returned to the main menu. Handling invalid menu choices was important because users can enter unexpected responses. The to-do list helped me practise storing changing information in a list. I also learned to use loops to keep menus running and conditionals to make decisions. Handling invalid numbers and division by zero made the calculator more reliable. With one more week, I would add the ability to save to-do tasks to a file so they remain available after the program closes.
